## Change Safety

- 6개 본활동을 4개 상위 모드로 묶는 구조를 보존한다: 미사일 모드(활동 1·2), 그림 모드(활동 3·4), 도둑 잡기 모드(활동 6), 문제 만들기 모드(활동 5).
- `명령을 효율적으로 쓰기`는 6개 본활동과 구분되는 별도의 기초 연습으로 유지한다.
- 일반 접속은 4개 모드 전용 선택 화면에서 시작하고, 공유 문제 접속은 선택 화면을 건너뛰어 해당 문제를 바로 연다.
- 플레이 중에는 헤더의 첫 화면 복귀와 접이식 빠른 모드 변경을 모두 제공한다.
- 빠른 변경을 펼쳤을 때 모드 선택 → 활동 선택 → 도전 방식 설정의 위계를 보존한다.
- 미사일·장애물·도둑 잡기·기초 연습의 사용자용 크기는 `5x5`, `7x7`, `9x9`, `11x11`을 사용하고, 두 내장 그림 활동은 단순 확대 반복을 피하기 위해 `5x5`, `7x7`, `9x9`만 사용한다. 문제 만들기·공유 그림은 `11x11`도 허용한다. 입문·표준·도전·확장 같은 난이도 명칭은 노출하지 않는다.
- 선택한 크기 안에서는 모든 도전 방식이 중복 없는 무작위 문제 가방을 사용하며, 해당 크기의 문제를 모두 사용한 뒤에만 새 가방을 섞는다.
- 장애물 없는 문제와 장애물 있는 문제는 별도 문제군으로 분류한다. 두 문제군이 모두 존재할 때는 한쪽 유형이 불필요하게 몰리지 않도록 문제 가방에서 균형 있게 섞는다.
- 장애물 수를 난이도의 대용으로 사용하지 않는다. 장애물 문제에는 하한을 두지 않으며, 크기별 상한은 `5x5 5개`, `7x7 6개`, `9x9 8개`, `11x11 10개`로 유지한다.
- 내장 장애물은 하나씩 제거해도 최단거리·최적 경로 수 또는 최단 체포 차례·최적 체포 명령 수가 그대로인 장식용 배치를 허용하지 않는다.
- 데스크톱·태블릿 가로·모바일 가로에서는 모눈종이와 명령 조합 패널을 나란히 배치한다.
- 태블릿·모바일 세로에서는 모눈종이 다음에 명령 패널을 배치하고, 가로 전환 시 터치 영역 44px과 가로 넘침 없는 2열을 유지한다.
- 활동 전환 시 이전 실행, 애니메이션, 결과창, 명령 강조, 타이머가 남지 않아야 한다.
- 미사일 이동과 장애물 피하기는 `최단 이동`과 `최소 명령`을 서로 독립된 풀이 기준으로 제공한다. 최단 이동은 실제 8방향 이동 칸 수가 최소일 때, 최소 명령은 장애물과 경계를 통과하지 않고 목표에 도착하는 방향·거리 명령 묶음 수가 최소일 때 성공한다. 같은 방향으로 연속된 명령은 한 묶음으로 정규화하며, 여러 풀이 찾기는 최단 이동 기준을 사용한다.
- 미사일·그림 모드의 시작과 플레이 설정은 `교육모드`와 `도전모드`를 같은 수준에서 분리한다. 교육은 처음 접속한 학생만을 위한 안내가 아니며, 완료 뒤에도 언제든 다시 들어가 복습하거나 저장된 지점부터 이어갈 수 있어야 한다. 도전 화면의 기본 선택지는 `자유 도전`, 정해진 문제 수 도전, `60초 도전`, 미사일의 `여러 풀이 찾기`로 간결하게 유지하고, 과거 `계속 도전` 데이터는 내부 호환만 보존한다.
- 미사일 모드의 기존 활동을 없애지 않고 별도의 `개념 교육`을 제공한다. 5x5·7x7은 순차구조 → 여러 길 → 같은 방향 명령 묶기 → 최단 경로 → 최소 명령, 9x9은 명령 블록 A 만들기와 반복, 11x11은 명령 블록 A·B 조합 순서로 구성한다.
- 개념 교육은 모든 입력 기능을 처음부터 열지 않는다. 순차구조와 여러 길은 1칸 명령으로 고정하고 맵에 필요한 방향만 제공하며, 명령 묶기부터 거리 조절을 연다. 최단 경로·최소 명령은 8방향을 모두 사용하고, 9x9 명령 블록 A 단계의 메인 실행에서는 직접 이동을 막으며, 11x11에서만 A·B와 메인 연결 명령을 함께 허용한다. 제한은 해당 개념과 맵의 정답 구조에 근거해야 한다.
- 순차구조 문제는 번호 지점을 정해진 순서로 통과하도록 설계하고, 여러 길 문제는 두 방향의 1칸 명령 순서만 바꾸어 같은 목표에 도달하는 서로 다른 과정을 비교하게 한다. 최소 명령 문제는 최단 경로에서 필요한 최소 명령 수보다 전체 안전 경로의 최소 명령 수가 실제로 더 작은 장애물 맵만 사용한다.
- 9x9·11x11 패턴 교육의 코드 수는 `메인 실행 블록 수 + 실제 사용한 명령 블록 정의 안의 명령 수`로 계산한다. 명령 블록은 메인에서 두 번 이상 반복되어야 하며 11x11은 A와 B를 모두 사용한다. 각 문제의 최소 코드 수는 목표 1칸 이동열을 대상으로 완전탐색해 검증하고, 번호가 표시된 연료 보급 지점은 제시 경로의 실행 순서를 확인하는 체크포인트로 사용한다.
- 미사일 모드의 `여러 풀이 찾기`는 같은 문제를 유지한 채 서로 다른 최단 방향 순서를 반복 제출한다. 최단보다 긴 도착 경로와 이미 제출한 방향 순서는 새 풀이로 세지 않으며, 명령을 묶은 방법만 다른 동일 경로도 중복으로 처리한다.
- 내장 미사일·장애물 문제는 가능한 모든 1칸 단위 최단 방향 순서를 정답 목록으로 열거해 보관하고, 분석된 최단 경로 수와 목록 수가 정확히 일치해야 한다.
- 여러 풀이 찾기는 시스템이 열거한 모든 최단 답안을 인정하되, 학생의 완료 목표는 서로 다른 풀이 3개로 둔다. 목표 뒤에도 새로운 최단 답안은 계속 저장·인정하며, 전체 답안을 모두 제출하게 요구하지 않는다.
- 화면과 활동지의 명령 조합은 활동 종류와 관계없이 `[칸수+방향기호]` 형식(예: `[3↗] [2→] [1↗]`)을 기본으로 표시한다.
- `그림 보고 명령 만들기`의 기본 성공은 특정 명령열이 아니라 최종 그림을 이루는 1칸 선분의 집합으로 채점한다. 선을 그은 순서·진행 방향·같은 선을 다시 지난 횟수는 무시하고, 목표에 없는 선이 추가되거나 목표 선이 빠진 경우에만 다른 그림으로 판정한다.
- `명령 보고 그림 그리기`의 제시 명령은 정답 비교 기준이지 이동 제한이 아니다. 화면에 어떤 방향이 제시되어 있어도 학생은 인접한 8방향 어디로든 이동할 수 있고, 틀린 이동도 그대로 그려지고 기록되어야 한다. 정답 여부는 제출할 때 제시 명령의 순서와 최종 그림을 함께 비교해 판정한다. 먼 칸을 한 번에 선택하는 입력은 정답 방향과 무관하게 가로·세로·대각선 중 하나의 일직선 이동일 때 허용한다.
- 그림 모드의 기존 활동·도전 방식을 보존하면서 별도의 `개념 교육`을 제공한다. 그림 교육은 5x5·7x7·9x9에서 `순서대로 그림 그리기 → 같은 그림, 다른 방법으로 그리기 → 가장 적은 명령으로 그림 그리기`의 3단계로 구성하고 11x11은 사용하지 않는다. 두 번째 단계는 같은 명령을 다른 순서로 쓰는 방법과 실제 경로·명령 조합이 다른 방법을 하나의 ‘다른 방법’ 개념으로 다룬다.
- 개념 교육은 단계·크기별로 최소 8개의 검증된 후보 문제은행을 두고, 한 번의 학습에서는 그중 중복 없는 5문제를 골라 제공한다. 선택된 5문제를 모두 성공한 뒤에만 다음 단계의 첫 문제로 자동 전환하며, 같은 단계를 다시 시작하면 앞 세트에 없던 문제를 우선 고른다. 새로고침할 때는 선택된 문제 세트를 그대로 복원한다. 마지막 단계 완료 후에는 처음 단계로 순환하지 않고 과정 완료 상태를 안내한다.
- 교육 한 차시의 선택된 문제는 격자 크기가 아니라 실제 구조 복잡도에 따라 쉬운 문제부터 배열한다. 구조 복잡도는 경로 길이, 방향 전환, 장애물 우회, 최단 이동과 최소 명령의 차이, 연료 지점과 명령 블록 수, 그림 선과 붓 상태 전환으로 계산하며 단순히 큰 모눈을 높은 난도로 취급하지 않는다.
- 그림 교육의 ‘같은 그림, 다른 방법’ 판정은 명령을 1칸 방향 순서로 펼쳐 비교한다. 같은 이동을 거리 명령으로 합치거나 나누기만 한 경우와 무동작 `붓 누르기`·`붓 떼기`만 덧붙인 경우는 새 풀이로 세지 않으며, 문제마다 의미 있게 다른 두 가지 풀이를 목표로 한다.
- 그림 교육의 최소 명령 단계는 주어진 시작점에서 정확한 그림을 완성하는 전체 명령 수를 판정한다. 방향·거리 명령 묶음 하나와 `붓 누르기`, `붓 떼기`는 각각 1개 명령으로 센다. 최소 붓 이동 칸 수는 보조 지표로 표시하되 성공 기준은 아니며, 문제별 최소 명령 수는 검증 가능한 증인과 하한으로 확보한다.
- 명령을 조립하는 그림 활동은 실행 전 붓을 뗀 상태로 간주하고, 명령 큐의 첫 칸에 `[붓 누르기]`를 기본 제공한다. 이 명령도 1개로 세며 사용자가 삭제·복원·재정렬할 수 있어야 한다. 최소 명령 문제에는 붓을 중간에 떼야만 추가 선 없이 완성할 수 있는 끊어진 그림을 크기별로 포함하고, 동일한 최소 명령 수로 완성하는 서로 다른 실행 순서도 모두 정답으로 인정한다.
- 교육모드의 완료 단계, 현재 단계·문제, 입력 중인 명령 조합과 여러 풀이 기록은 브라우저의 로컬 저장소에 검증된 형식으로 저장해 새로고침 뒤에도 이어서 학습할 수 있게 한다. 첫 화면으로 명시적으로 돌아간 경우에는 자동 재진입하지 않되 완료 기록은 보존한다.
- 그림의 효율 지표는 주어진 붓 시작점에서 목표 선을 모두 덮는 최소 붓 이동 칸 수로 계산한다. 기본 설정에서는 더 긴 완성 경로도 성공이고 최소 이동은 완전 성공이며, `최소 붓 이동만 성공 인정` 설정을 켠 경우에만 최소 횟수를 요구한다.
- 도둑 잡기는 장애물이 없는 문제와 장애물이 있는 우회 문제를 함께 유지한다. 장애물은 경찰·도둑 모두 통과할 수 없고, 공개된 도둑 경로를 막지 않으며 도주 완료 전에 체포 가능한 배치여야 한다.
- 도둑 잡기의 각 크기 문제군은 단순한 좌표 교환이 아니라 단일 관문·이중 관문·꺾인 장벽·포위형처럼 서로 다른 길찾기 구조를 포함한다. 도둑의 공개 경로는 같은 칸을 왕복하지 않고 방향 선택이 세 차례 이상 달라져야 한다.
- 도둑 잡기의 경찰 명령은 매 차례 8방향 중 한 칸 이동만 허용하며, 문제 검증과 최적 체포 경로 계산도 같은 동작 집합을 사용한다.
- 미사일·장애물·도둑 잡기 문제는 같은 최소 길이 또는 같은 최단 체포 차례의 서로 다른 명령열을 두 개 이상 허용한다.
- 장애물 문제는 장애물 없는 체비쇼프 거리보다 실제 최단거리가 충분히 길어야 하며, 도둑 잡기 장애물 문제는 장애물이 가장 이른 체포 차례를 실제로 늦춰야 한다.
- 장애물 문제는 크기별 10문제 중 적어도 5문제가 두 칸 이상 우회해야 하며, 7x7 이상에서는 적어도 2문제가 세 칸 이상 우회해야 한다. 최단 경로 수 상한은 `5x5 20개`, `7x7 48개`, `9x9 96개`, `11x11 192개`로 관리한다.
- 그림 문제는 회전·반전·이동만 다른 복제를 허용하지 않고, 가지 선택점과 서로 다른 고리 수를 포함하는 연결 그래프로 구성한다.
- 같은 그림 소재를 여러 크기에서 사용할 때는 단순 확대·축소만 한 문제를 허용하지 않는다. 기본 `그림 보고 명령 만들기`와 `명령 보고 그림 그리기` 문제은행은 크기별 소재를 겹치지 않게 구성하거나, 같은 소재라면 선·가지·고리·붓 이동 구조 중 하나 이상이 달라야 한다.
- 내장 그림 문제는 가로·세로 모두 `5x5 4칸`, `7x7 5칸`, `9x9 6칸` 이상의 범위를 사용하며, 격자점이 아닌 곳에서 대각선끼리 교차해 연결 여부가 모호해지는 그림을 허용하지 않는다.
- 내장 도둑 잡기 문제는 도둑 경로의 벽·장애물 충돌과 경찰의 체포 가능성을 불러오기 전에 검증한다.
- 사용자 입력은 안전하게 검증하고, 공유 데이터는 비정상 크기·경로·명령을 허용하지 않는다.
- 외부 서비스, 분석 도구, 계정 기능, 배포 설정은 명시적 요청 없이 추가하지 않는다.
