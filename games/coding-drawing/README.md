# 모눈종이 코딩 놀이터

8방향 모눈종이에서 미사일 이동, 그림 알고리즘, 도둑 잡기, 문제 만들기를 연습하는 정적 웹앱입니다.

개발 기준은 GitHub `LUCKYBRIDGE/knolcoding` 저장소의 이 폴더입니다(2026-10-31부터). 아래 로컬 경로의 사본은 추후 이 저장소의 최신 내용으로 맞춥니다.

- macOS: `/Volumes/WAN2/apps/coding-drawing`
- Windows: `<외장하드 문자>:\apps\coding-drawing`
- Pinky NE의 `games/coding-drawing/`은 배포용 복사본입니다.

## 학습 구조

6개의 본활동은 다음 4개 상위 모드로 묶습니다.

- 미사일 모드: `1. 미사일 이동`, `2. 장애물 피하기`
- 그림 모드: `3. 그림 보고 명령어 만들기`, `4. 명령어 따라 그림 그리기`
- 도둑 잡기 모드: `6. 도둑 잡기`
- 문제 만들기 모드: `5. 나만의 문제 만들기`

`명령을 효율적으로 쓰기`는 6개 본활동에 포함하지 않는 별도의 기초 연습입니다.

처음 접속하면 4개 모드 카드가 있는 전용 선택 화면이 열립니다. 활동을 시작한 뒤에는 상단의 `빠른 모드 변경`을 펼쳐 현재 화면에서 다른 활동으로 이동하거나, 헤더의 `모드 변경`을 눌러 첫 선택 화면으로 돌아갈 수 있습니다. 공유 문제 링크는 선택 화면을 건너뛰고 해당 문제를 바로 엽니다.

## 가장 쉽게 실행하기

`index.html`을 직접 열면 브라우저의 보안 정책 때문에 앱 모듈이 차단됩니다. 다음 실행 파일을 사용하세요.

- macOS: `start-coding-playground.command`를 두 번 클릭
- Windows: `start-coding-playground.cmd`를 두 번 클릭
- 공통 터미널 명령: `npm run start:local`

처음 실행하거나 외장하드를 다른 운영체제의 컴퓨터로 옮긴 뒤 실행하면, 현재 컴퓨터에 맞는 `node_modules/`를 자동으로 다시 준비하고 `http://127.0.0.1:5173/`을 엽니다.

Mac에서 실행 권한 안내가 나타나면 프로젝트 폴더의 터미널에서 `npm run start:local`을 사용하면 됩니다. 실행 파일은 편의를 위한 진입점이며, 프로젝트 실행 자체는 파일 권한에 의존하지 않습니다.

## 처음 준비하기

각 컴퓨터에 Node.js 22 LTS와 Git을 설치합니다. 프로젝트 폴더에서 버전을 확인한 뒤 의존성을 설치합니다.

```sh
node --version
npm --version
npm ci
```

기준 버전은 Node.js `22.17.0`, npm `10.9.2`입니다. `.nvmrc`와 `.node-version`을 지원하는 버전 관리 도구를 사용하면 자동으로 같은 버전을 선택할 수 있습니다.

`node_modules/`는 macOS와 Windows 사이에서 공유하지 않습니다. `npm run start:local`은 운영체제가 바뀐 것을 확인하면 `npm ci`를 자동으로 실행합니다. 수동으로 준비하려면 컴퓨터를 바꾼 뒤 `npm ci`를 실행하세요.

## 개발하기

```sh
npm run start:local
```

자동으로 브라우저에서 `http://127.0.0.1:5173/`을 엽니다. 브라우저를 자동으로 열지 않고 개발하려면 `npm run dev`를 사용합니다.

전체 검증은 한 명령으로 실행합니다.

```sh
npm run check
```

이 명령은 실행 환경, 휴대 가능한 파일 이름, 자동 검사, 프로덕션 빌드를 차례로 확인합니다.

## 컴퓨터를 바꾸기 전

1. 개발 서버와 편집기를 닫습니다.
2. `npm run check`를 실행합니다.
3. `git status`로 저장되지 않은 작업을 확인합니다.
4. 이어서 사용할 작업은 커밋합니다.
5. 운영체제에서 WAN2 외장하드를 안전하게 추출합니다.

외장하드에 있는 `node_modules/`, `dist/`, `.vite/`는 언제든 다시 만들 수 있으므로 작업 기록으로 취급하지 않습니다.

## Pinky NE에 반영하기

WAN2에서 먼저 `npm run check`를 통과시킨 뒤, 검증된 소스만 `LUCKYBRIDGE/pinky-ne-site`의 `games/coding-drawing/`에 동기화합니다. Pinky 저장소에서 다음 검사를 다시 실행합니다.

```sh
npm run test:coding-drawing
npm run build
```

GitHub 반영과 실제 배포는 서로 별개의 작업입니다. 명시적으로 요청된 범위만 커밋·푸시·배포합니다.
